# Datasheets

The manufacturers' datasheets this project's footprints, pinouts and placement rotations
were checked against.  They are not kept in the repository (they are the makers' documents
to publish); download each one here under the file name shown, which is the name the code
comments and `pcb/README.md` refer to.  `*.pdf` in this folder is ignored by git.

| File | Part | Used for | Datasheet |
|---|---|---|---|
| `C41417453.pdf` | SHOU HAN TYPE-C 16P 3MD 040, USB-C receptacle (J1) | the J1 footprint (`gen_fp.py`), its placement rotation | [LCSC C41417453](https://www.lcsc.com/product-detail/C41417453.html) |
| `C2886570.pdf` | OPSCO SK6812MINI-012, RGB LED (LED1-LED92) | LED pinout against the footprint, pin-1 dot | [LCSC C2886570](https://www.lcsc.com/product-detail/C2886570.html) |
| `C5183448.pdf` | OPSCO SK6812MINI-B-012, the LED first chosen | same pins and lands as the -012 | [LCSC C5183448](https://www.lcsc.com/product-detail/C5183448.html) |
| `C109471.pdf` | WCH CH446Q, crosspoint (U3) | the CH446Q symbol, placement rotation | [WCH CH446DS1](https://www.wch-ic.com/downloads/CH446DS1_PDF.html), [LCSC C109471](https://www.lcsc.com/product-detail/C109471.html) |
| `C2980299.pdf` | Espressif ESP32-S3-MINI-1U-N8 (U1) | pin layout, placement rotation (the copy used was the Chinese edition, v1.2) | [Espressif, English](https://www.espressif.com/sites/default/files/documentation/esp32-s3-mini-1_mini-1u_datasheet_en.pdf), [LCSC C2980299](https://www.lcsc.com/product-detail/C2980299.html) |
| `C2832236.pdf` | TI CD74HC154M96, column decoder (U6) | pinout, placement rotation | [TI cd74hc154.pdf](https://www.ti.com/lit/ds/symlink/cd74hc154.pdf), [LCSC C2832236](https://www.lcsc.com/product-detail/C2832236.html) |
| `C7519.pdf` | ST USBLC6-2SC6, USB ESD protection (U7) | package and marking drawings, placement rotation | [LCSC C7519](https://www.lcsc.com/product-detail/C7519.html) |
| `C125979.pdf` | Nichicon UWT1C221MCL1GS, 220 uF 16 V (C5) | terminal orientation, placement rotation | [LCSC C125979](https://www.lcsc.com/product-detail/C125979.html) |
