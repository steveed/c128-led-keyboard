# C128 keycap legend map

Everything needed to order a keycap set for this keyboard: which legend goes on which key,
what color each key is, and vector artwork for the front-face PETSCII glyphs.

Generated by [`legend_map.py`](legend_map.py) from the switch positions in the PCB.  Legends
were checked against a Commodore 128 keyboard photo; the PETSCII glyphs use the Unicode 13
"Symbols for Legacy Computing" mapping.

## Layout conventions (from the original C128)

- **Colors**: the 16 top-row keys (ESC…CAPS LOCK, HELP…NO SCROLL, the four cursor arrows,
  F1–F8) are the dark color; every other key is the light color.
- **Top legends**: letters are single centerd capitals.  Keys with a shifted symbol carry it
  above the main legend (`!` over `1`, `[` over `:`).  Two-word keys are on two lines
  (`CLR` / `HOME`).  Function keys read `F1` upper-left / `F2` lower-right.  The `0` is slashed.
  The left modifier reads `CONTROL`, not CTRL.  Keypad `ENTER` is a vertical 2u with rotated text.
- **Front legends**, left to right:
  - letters, `+`, `−`, `£`, `@`, `*`: two boxed graphics — the **Commodore-key** graphic on the
    left, the **Shift** graphic on the right.  Each glyph is drawn inside a thin square outline
    (its character cell), exactly as printed on the original.
  - `↑`: a single boxed `π` (Shift).
  - `1`–`8`: two color abbreviations, CTRL color over Commodore-key color
    (`Blk`/`Orng`, `Wht`/`Brn`, `Red`/`L Red`, `Cyn`/`D Gry`, `Pur`/`M Gry`, `Grn`/`L Grn`, `Blu`/`L Blu`, `Yel`/`L Gry`).
  - `9`: `Rvs` / `On`; `0`: `Rvs` / `Off`.
  - nothing on any other key.

## Notes for ordering

- The SVG glyph boxes are 3.2 mm square with a 0.9 mm gap; the color abbreviations are 2.2 mm
  bold sans.  Scale to taste for the front face of the profile you order (DCS row-dependent).
  Everything is plain black fills/strokes, so it takes any color.
- The four card suits, `π`, `●` and `○` are set as text/circles in the SVG; the engraver or
  printer will have their own preferred rendering of those.  All block and line graphics are
  geometry on an 8×8 grid, matching the C64/C128 character ROM proportions.
- `legend_map.csv` carries the PETSCII code and Unicode code point for every glyph, so a
  vendor with a PETSCII font (e.g. "C64 Pro Mono") can typeset them directly instead of
  using the SVGs.
